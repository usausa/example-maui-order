# README

## 内容

- README は概要、主要な画面の画像と一言の説明、`docs/` の文書へのリンク、全体の進捗の表、基にしたテンプレートへのリンクだけにする
- AI 向けの規則 (`AGENTS.md`、`.claude/`) は載せない
- 概要は数行にし、端末の一覧 (機器、利用者、主な機能) は表にする
- 文書の表は、文書へのリンクと、主な章を括弧で添えた短い説明にする
- 基にしたテンプレートは最後の表に、リポジトリへのリンクと基にしたものを書く
- 詳細な説明は README に書かず、`docs/` の文書に置く

## 画面の画像

- 端末ごとの小見出しの表に並べ、画像の下に「画面名。一言の説明」を書く
- エミュレータで撮った画像を半分の大きさにして `docs/images/` に置く (テーブル端末・キッチン端末は 960x600、受付機は 600x960、ホール端末は 540x1200)
- ホール端末は日本語で撮る (`emu.py locale ja-JP`)
- キッチン端末は、エミュレータのブラウザを日本語にして (`emu.py browse --locale ja-JP`)、全画面で撮る
- 管理画面は PC のブラウザで表示を 1440x842 にして 2 倍の解像度で撮り、960x561 に縮める (デモのテナント管理者でサインインして撮る)

## 進捗の表

- 対象 (端末、サーバ、管理画面、本番の環境など) ごとに、状態 (✅ 実装済み、🚧 一部実装、⬜ 未着手)、実装済み、未実装を書く
- セルは要点だけにし、細目は計画 (`docs/plan.md`) と構成 (`docs/architecture.md`) に置く
