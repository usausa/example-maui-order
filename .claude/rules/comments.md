# コメント

- コメントは日本語で書く
- コードから読み取れない意図、制約、理由があるときだけ書く (コードの言い換えは書かない)
- 1 つのコメントは 1〜2 文を目安に短くする
- 既存のコメントは、そのコードを変えるときに今の用語に直す
- XML ドキュメントコメントは付けず、区切りコメント (`// Xxx` と、`//----` で挟んだ見出し) でまとめる
- 区切りの見出しは英語の名詞でよい
- 設計文書 (文書名、節番号、画面 ID) を参照しない (ソースが正)
