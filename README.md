# example-maui-order

.NET MAUI (Android のタブレット) で作る、ファミリーレストラン向けのテーブルオーダー端末のサンプル。  
テーブルに置いたタブレットで、お客様がメニューを見て注文し、注文履歴の確認、店員の呼び出し、テーブルでの会計を行う。  
いまは画面のモックを作る段階で、通信はモックの応答を返す。
